Connect STAR-X to Supabase

Follow these steps in order. You only need your Supabase Project URL and public publishable key for the browser configuration.

Important: This upgrade connects customer registration/sign-in to Supabase Auth and prepares a secure starter database. The product admin dashboard is still a demo; online payments, order processing, private software downloads and secure admin roles are not enabled yet.

Step 1 — Open your Supabase project

  1. Go to Supabase Dashboard.
  2. Open your project named STAR-X-STORE.
  3. Copy the Project URL from the project Connect panel or API settings.
  4. Open Settings → API Keys and copy the Publishable key (often starts with sb_publishable_).

Step 2 — Paste the two public values

  1. In this website folder, right-click supabase-config.js.
  2. Choose Open with → Notepad.
  3. Replace only the two placeholder values below with your own values. Keep the quotation marks.
  4. Save the file.
window.STARX_SUPABASE_CONFIG = {
  url: "https://YOUR-PROJECT-REF.supabase.co",
  publishableKey: "sb_publishable_YOUR_PUBLIC_KEY"
};

Do not add your key to index.html, README.md or a public social post. The publishable key is intended to be public, but database access must be protected by RLS policies.

Step 3 — Create the starter database

  1. In Supabase, open SQL Editor.
  2. Choose New query.
  3. Open this folder's supabase-setup.sql in Notepad.
  4. Copy all its contents and paste them into the SQL Editor.
  5. Click Run. Confirm the query succeeds.

The script creates a public product catalogue and a private enquiries table. Visitors can submit enquiries, but cannot read other customers' enquiries.

Step 4 — Configure customer sign-in

  1. In Supabase, open Authentication → URL Configuration.
  2. Set Site URL to your published GitHub Pages website address, for example https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY/.
  3. Add that same site address to Redirect URLs, then save.
  4. Upload the updated website folder to GitHub Pages.
  5. Open account.html on your published website and test registration with an email address you control. Check your inbox if email confirmation is enabled.

Step 5 — Verify the connection

  1. Open the published website's account.html.
  2. Try creating a test account.
  3. If it says Supabase is not configured, check supabase-config.js and make sure you saved it.
  4. If a browser error appears, check that the Project URL and Publishable key were copied completely.
Security rules
  • Never use a Supabase secret key or legacy service_role key in this website.
  • Never put your database password, payment credentials or private software download URLs in JavaScript.
  • Do not use the demo dashboard for real customer records.
  • Before accepting payments or selling downloads automatically, add a trusted server-side backend and payment verification.
